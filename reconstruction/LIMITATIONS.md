# الفروق والحدود

## إعادة تنفيذ مستقلة

لا توجد شفرة إنتاج مفكوكة داخل runtime ولا موارد أو كلمات مرور من لسانا. الحالات المثبتة في الاختبارات المصطنعة هي مرجع سلوكي. لا ندّعي أن هذه نسخة من المشروع الأصلي أو أن كل استثناء في Unicode أو كل حركة واجهة تطابقه.

## الأجزاء المستقلة عمدًا

- جدولة المراجعة ladder معلن، لا SM-2 أو FSRS ولا خوارزمية لسانا غير المكشوفة.
- SQLite وجلسات زائر محلية للمضيف، بدل خدمات الإنتاج الأصلية.
- ثلاث قصص و18 سطرًا ورسوم جديدة و36 MP3 مولّدًا محليًا.
- الواجهة اسمها «سطر»، ولا تنسخ هوية أو رسومات أو تصميم إنتاج pixel-for-pixel.
- الحقل ظاهر للمستخدم ولتقنيات المساعدة؛ الأصل كان يستخدم حقلًا مخفيًا بصريًا.
- لا يتوفر shared-file segment player أو ملفات سرعة مسبقة؛ الملفات مستقلة لكل سطر مع playbackRate.

## غير منفّذ

لا حسابات بريد أو استعادة حساب أو مزامنة أجهزة أو دفع أو لوحة تحرير/إدارة أو توليد قصص لحظي أو خدمة LLM أو نظام تحميل مستخدمين. القاموس مشتق من الكلمات الأصلية للأسطر المكتملة. لا يوجد تقليد لعبة التحدي الكاملة ذات 495 كلمة؛ الطلب الحالي يركز على القصص والمحرك والصوت والتقدم والمراجعة، ولم يُنسخ بنكها.

## الصوت والمتصفح

الصوت الحالي منخفض التكلفة وبسيط، وليس Neural احترافيًا. جرى التأكد من فك الملفات وتقدم وقت التشغيل والسرعات؛ لم يجرَ تقييم سمعي تربوي. المسار البديل speechSynthesis يعتمد على وجود أصوات إنجليزية في الجهاز، وقد لا يتوفر في البيئة السحابية؛ حالة غياب الملف لا توقف الكتابة. فشل نطق كلمة القاموس لا يعرض رسالة مفصلة حاليًا.

## الاستمرارية والسعة

حفظ التقدم مؤكد على مستوى السطر وبعد refresh. المدخل الجزئي لا يستعاد بعد إغلاق الصفحة. طابور localStorage محدود بآخر 200 محاولة؛ تعطيل التخزين أو امتلاء حصته ليس حالة مستعادة بالكامل في هذه النسخة. تنشئ جلسات المتصفح الجديدة مساحة جديدة؛ حذف Cookie يفقد رابط الهوية القديمة. مسح localStorage قبل مزامنة المحاولات يزيلها.

لا يوجد Service Worker أو تشغيل صفحة جديدة offline؛ الاختبار يثبت إكمال سطر محمّل أثناء انقطاع طلب الحفظ، ثم المزامنة. SQLite تحتاج قرصًا دائمًا ونسخة تشغيل واحدة؛ لم يُختبر clustering أو load كبير. مؤشرات الاستحقاق تعتمد على ساعة الجهاز عند العرض؛ موعد التخزين يحسبه الخادم.

## ما تثبته الاختبارات وما لا تثبته

Chromium مفحوص محليًا، مع viewport desktop وmobile. لم تُفحص أجهزة iOS/Android فعلية أو Safari/Firefox أو قارئ شاشة فعلي أو استعادة backup أو Docker أو نشر سحابي. لا تمثل سيناريوهات التكلفة سعة مستخدمين مختبرة. لم يتم انتظار 60 يومًا؛ اختبارات الوقت حقنية لدالة الجدولة، والمراجعة التفاعلية تستخدم موعدًا معدلًا في SQLite الاختبار فقط.
