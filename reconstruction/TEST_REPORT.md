# تقرير الاختبارات الفعلية

تاريخ التنفيذ: 7 نوفمبر 2026. التطبيق اختُبر على خادم **Next.js production** محلي، مع Node.js 24.22.1 وChromium النظام، بواسطة Playwright 1.65.0. الصوت فعلي محلي وليس mock في اختبار التشغيل؛ mock 404 استعمل فقط لاختبار الفشل.

النسخة النهائية من التقرير الآلي هي المرجع في حال إعادة تشغيل المشروع لاحقًا. لا تتطلب أي من الاختبارات بيانات أو حسابًا من لسانا.

## حالات الوحدة

سبع حالات من اختبارات الحزمة السابقة: الصحيح، بقاء خطأ عند النهاية، الحذف والتصحيح مع بقاء الخطأ في العداد، إعادة محاولة الأغلبية الخاطئة، تجاهل حالة الحرف، تجاوز الترقيم، وإعادة ضبط العربية. اختبارات جديدة لحالات العرض بعد التصحيح، وإلزام الترقيم، ومنع تعديل نتيجة منتهية، وحفظ الأرقام العشرية، وفترة العشر دقائق، وسلم الفترات وسقفه وإعادة ضبطه بعد خطأ.

أضيفت ثلاثة اختبارات للعبة: ترتيب حتمي لكلمات القصص الأصلية، خطأ/صحيح/تجاوز، وانتهاء الدقيقة ومنع النتيجة المتأخرة.

## حالات المتصفح التسع عشرة

1. عرض القصص الأصلية ولقطة سطح مكتب و390px دون تجاوز أفقي.
2. حرف خاطئ ثم Backspace وتصحيح: بقاء العداد وعلامة التصحيح ودقة 50% للعينة.
3. ظهور تنبيه لوحة المفاتيح العربية.
4. فك MP3، تقدم currentTime، السرعات الأربع وغياب media.error.
5. وضع الاستماع وإخفاء الترجمة.
6. وضع الترقيم لا يكمل قبل النقطة الأخيرة.
7. إكمال القصة ذات الأسطر الستة، ثم refresh وبقاء التقدم وتجميع الكلمات، وجدولة اليوم.
8. استئناف القصة من أول سطر غير مكتمل بعد refresh.
9. جلستان مستقلتان: تقدم الأولى لا يعود للثانية.
10. تكرار UUID المحاولة لا يغير attempts أو dueAt.
11. قطع POST الحفظ: journal محلي؛ بعد إزالة القطع تنجح المزامنة.
12. موعد مراجعة مستحق ثم مراجعة تفاعلية تنقله إلى ثلاثة أيام.
13. MP3 مفقود 404 يظهر تنبيهًا ولا يمنع الكتابة.
14. API يرفض Origin أجنبيًا وكتابة بلا جلسة ومدخلًا غير مكتمل أو بنية غير صالحة.
15. قصة غير موجودة تعيد 404 فعليًا، وX-Frame-Options وframe-ancestors موجودان.
16. سطر مكتمل بخطأ واحد يحفظ ويحدد عشر دقائق ويعيد streak للصفر.
17. فشل GET الحالة يعرض إعادة اتصال ثم ينجح بعد عودة الاستجابة.
18. تجاوز الحجم 413، ونوع نص 415، وJSON تالف أو `null` بحالة 400.
19. لعبة الكلمات الأصلية: إجابة خاطئة ثم صحيحة، تجاوز، انتهاء دقيقة بساعة Playwright، وبقاء أفضل نتيجة بعد إعادة التحميل.

## فشل التشغيل الأول وما عولج

التشغيل الأول نفّذ 15 اختبارًا: **10 نجحت و5 فشلت**. حُفظ `evidence/playwright-results-initial.json` و`evidence/e2e-run-1.log` دون إخفاء النتائج.

- اختبارا التنبيه فشلا بسبب `getByRole('alert')` الذي طابق تنبيه التطبيق وتنبيه route-announcer الداخلي لـNext.js معًا. استُخدم ترشيح بحسب نص التنبيه. كانت الرسائل المطلوبة ظاهرة فعلًا.
- اختبارات العزل وidempotency والمراجعة أرسلت API قبل اكتمال تهيئة Cookie في الصفحة، فرفضت الكتابة بلا جلسة كما ينبغي. عُدّل إعداد الاختبار ليطلب `/api/state` قبل التدفق؛ لم يُخفف التحقق في المنتج.
- ظهرت أثناء إعداد البناء أخطاء JSX أولية وصححت قبل تشغيل المتصفح. احتاجت typings المكتبات إلى إعداد `skipLibCheck` المعتاد مع Next.js، مع استمرار strict على كود المشروع.
- أُضيف لاحقًا رفض جسم `null` صراحةً أثناء مراجعة التحقق، واختُبر ضمن الجولة النهائية.

لا توجد اختبارات محذوفة أو skipped لإخفاء خلل. حالات الشبكة والصوت وHTTP غير الصالح تُعد نجاحًا عندما يظهر الفشل المتوقع وتتعافى الواجهة حسب المواصفة.

فشل اختبار اللعبة بعد إضافتها عند استخدام `page.clock.fastForward(60_000)`، لأن القفزة نفذت callback للـinterval مرة واحدة ولم تمثل 60 tick. بقي السجل في `../evidence/phase10/game-e2e.log`. تغيّر الاختبار إلى `page.clock.runFor(60_000)` ونجح في `game-e2e-retry.log`؛ ثم أعيد تشغيل المجموعة الكاملة.

## حدود التحقق

اختبار المراجعة لا ينتظر يومًا فعليًا؛ بعد إنشاء نتيجة عبر API يضبط dueAt لسجل الجلسة داخل SQLite الاختبار فقط، ثم يكمل المراجعة عبر المتصفح ويقرأ الموعد الجديد من API. لا توجد واجهة خلفية في المنتج لتجاوز الوقت. اختبارات الجدولة النقية تحقن زمنًا ثابتًا للتحقق الحسابي.

لم يجر اختبار سمعي تربوي، أو Safari/Firefox أو أجهزة فعلية أو قارئ شاشة فعلي أو تحميل واسع أو استعادة backup أو بناء Docker. تعرض اللقطات والـviewport توافقًا بصريًا فقط للمقاسات المختبرة. المسار الصوتي البديل يعتمد على أصوات النظام ولا نعلن جودة/توفر كل صوت جهاز.

## إعادة التشغيل

```bash
npm ci
npm run typecheck
npm run test:unit
npm run build
npx playwright install chromium
npm run test:e2e
npx playwright show-report evidence/playwright-report
```

الخادم وقاعدة `.test-data/e2e.sqlite` مؤقتان للاختبار؛ لا يستخدم بيانات المستخدم في `private-data`. لا تشغّل خادمًا آخر على المنفذ 3000 بالتزامن مع E2E.
