# سطر — مشروع إعادة بناء مستقل

**تحديث المرحلة 21:** التطبيق الحالي صار أربع قصص/24 جملة، 120 كلمة في ست مجموعات، نص استماع بأربعة مقاطع، 58 ملف MP3 محليًا، ومفضلة ولعبة «كلمات تعرفها». ابدأ من `/home`. الأعداد الثلاث قصص/18 جملة/36 ملف أدناه تصف النسخة الأولى تاريخيًا؛ التقارير الحالية في المجلد الأعلى، خصوصًا `PUBLIC_CONTENT_INVENTORY.md` و`TEST_REPORT.md` و`KNOWN_LIMITATIONS.md`. يحتاج التشغيل Node 24 وقرصًا دائمًا لحفظ SQLite؛ لم يُنشر رابط HTTPS عام لهذه المرحلة.

مشروع Next.js يعمل محليًا، مستند إلى سلوك مثبت في حزمة الفحص، مع كود جديد وثلاث قصص أصلية. يشمل محرك كتابة وتصحيح، 36 ملف صوت مولّد محليًا، حفظ تقدم SQLite، ومراجعة متباعدة بخوارزمية مستقلة، ولعبة كلمات من قصصه الأصلية. لا يتصل بلسانا أو Supabase أو أي خدمة إنتاج.

## التشغيل

يتطلب Node.js **24.x** وnpm. ملفات الصوت جاهزة؛ لا تحتاج حساب خدمة أو FFmpeg للتشغيل المعتاد.

```bash
npm ci
npm run build
npm start
```

افتح `http://localhost:3000`. وللتطوير استخدم `npm run dev` بعد `npm ci`.

تُنشأ قاعدة البيانات تلقائيًا في `private-data/satr.sqlite`. تحفظ الجلسة في Cookie عشوائي HttpOnly، وتظهر النتائج لنفس المتصفح. لا توجد حسابات بريد أو مزامنة أجهزة. احتفظ بهذا المجلد عند إعادة التشغيل، وضعه على قرص دائم عند الاستضافة.

## الاختبارات الحقيقية

```bash
npm run typecheck
npm run test:unit
npx playwright install chromium
npm run test:e2e
```

اختبارات المتصفح تتطلب بناء المشروع أولًا، وتشغّل خادم إنتاج منفصلًا وقاعدة مؤقتة داخل `.test-data`؛ تأكد أن المنفذ 3000 متاح. على Linux يمكن تثبيت متطلبات Chromium عبر `npx playwright install --with-deps chromium` حسب صلاحيات جهازك. يستخدم الإعداد `/usr/bin/chromium` إن وجد، وإلا متصفح Playwright المثبّت. النتائج المسلّمة في `evidence/`، وقصص الاختبار في `tests/`.

## التوثيق: عشرة ملفات

| الملف | المحتوى |
|---|---|
| `README.md` | التشغيل وفهرس التسليم |
| `ARCHITECTURE.md` | المكوّنات، تدفق البيانات، قاعدة البيانات |

| `EVIDENCE_MAP.md` | الربط بأدلة الحزمة السابقة وبصمتها |

| `TEST_REPORT.md` | النجاح والفشل والحدود مع أدلة التشغيل |

هذه الملفات العشرة اعتمدت وفق اختيارك، وتشمل الملفات الثلاثة التي سمّيتها حرفيًا.

## أوامر إضافية

```bash
npm run costs
npm run audio:generate
npm run content:validate
```

الأول يعيد حساب التكاليف من الملفات الفعلية. الثاني اختياري لإعادة توليد الصوت الأصلي باستخدام FFmpeg مع فلتر `flite` وffprobe؛ والثالث يراجع ربط الجمل والترجمات والكلمات بالأصوات وبصماتها. راجع `OPERATIONS.md`. لا يستعمل مفاتيح أو خدمة توليد مدفوعة. يغطي التقرير الشامل في المجلد الأعلى سيناريو 100,000 مستخدم وحدود تكلفته.

القصص والرسوم والكود كتبت لهذا المشروع. استُخدمت من الحزمة السابقة اختبارات مصطنعة ونتائج سلوك فقط؛ لم تُنسخ القصص المدفوعة أو ملفات JavaScript الإنتاجية إلى التطبيق.
