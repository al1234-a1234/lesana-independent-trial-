# نموذج الأمان والخصوصية

## حدود الثقة

هذه نسخة تعلم مفتوحة بلا محتوى مدفوع أو بوابة دفع أو حساب بريد. الجلسة المجهولة هي رمز عشوائي 32 بايت في Cookie HttpOnly/SameSite=Strict، وSecure عندما يكون الطلب HTTPS. تخزن قاعدة البيانات بصمة الرمز فقط كمالك للسجلات؛ لا تستعمل أسماء أو عناوين بريد.

كل استعلام تقدم يقيّد `owner` القادم من Cookie؛ لا يُقبل owner أو userId في الجسم. يثبت اختبار جلستين أن الثانية لا ترى تقدم الأولى في التدفق المفحوص. فقدان Cookie يعني فقدان الوصول لهذا التقدم؛ لا توجد استعادة هوية أو نقل آمن بين أجهزة في هذه النسخة.

## حماية API

- `/api/state` يرجع `Cache-Control: private, no-store` وينشئ الجلسة عند اللزوم.
- POST يتحقق من Origin نفسه، وJSON، ووجود الجلسة، وحجم الجسم 128,000 بايت، وبنية المحاولة وحدود المدخلات.
- رفض origins غريبة 403، وغياب Cookie 401، ومدخل غير صالح 400، ونوع غير JSON 415، ونص غير مكتمل 422، وجسم كبير 413.
- الخادم يعيد تشغيل تاريخ المدخلات ويحسب التصحيح والجدولة؛ لا يثق بقيمة دقة مرسلة وحدها.
- معاملة SQLite ومفتاح المحاولة يمنعان جدولة مضاعفة لنفس الطلب.
- الاستعلامات تستخدم معاملات، ولا يقبل التطبيق مسار ملف صوت من مستخدم أو يجلب URL خارجيًا.

إعادة تشغيل تاريخ مدخلات يرسله العميل ليست إثباتًا لكون الكاتب إنسانًا: يستطيع العميل تصنيع تاريخ صحيح. لا تعتمد على هذا النظام وحده لمنح مال أو شهادات أو اشتراك. الوقت وإعادة الصوت أيضًا قياسات عميل، ولا تُعامل كحقائق أمنية.

## الواجهة والوسائط

React يهرب النصوص؛ لا يوجد `dangerouslySetInnerHTML`. CSP يقصر موارد التطبيق على نفسه، و`frame-ancestors 'none'` وX-Frame-Options DENY وnosniff وسياسة Referer وصلاحيات كاميرا/مايك مغلقة. CSP يسمح inline scripts/styles لملاءمة Next.js الحالية؛ سياسة nonce أدق ليست منفذة. HSTS/TLS مسؤولية واجهة HTTPS عند النشر، ولم يُفعّل HSTS على خادم HTTP المحلي.

كل ملفات الصوت والقصص المضمّنة أصلية ومفتوحة عمدًا. إن أضفت محتوى مدفوعًا لاحقًا، لا تضعه في `public/` أو JSON عميل؛ يلزم مخزن خاص وصلاحية لكل طلب ومعاينة منفصلة. هذه النسخة لا تدّعي تنفيذ فوترة أو استحقاق دفع.

## التخزين والتشغيل

SQLite تحت `private-data` خارج public؛ لا تشحن هذا المجلد أو `.env` أو قاعدة اختبارات ببيانات مستخدمين. طابور localStorage يضم مدخلات أسطر أصلية، ويمكن لسكريبت من نفس الأصل قراءته؛ ليس مكانًا لحفظ أسرار أو نصوص خاصة.

يجب حماية مضيف SQLite وأخذ نسخة احتياطية متسقة. لا يوجد تشفير إضافي على مستوى قاعدة البيانات أو حذف حسابات أو سياسة احتفاظ آلية. أضف تحديد معدل requests ومراقبة ومساحة محددة قبل طرح عام واسع؛ إنشاء جلسات مجهولة لا يمنع إساءة استهلاك مساحة المضيف.

## ما اختُبر

Origin خاطئ، غياب جلسة، عزل جلسات، عدم قبول نص غير مكتمل، حدود ونوع الجسم، idempotency، ترويسات منع framing. لم يُجرَ اختبار اختراق شامل أو مراجعة dependencies جنائية أو تحميل هجومي. لا توجد خدمات إنتاج خاصة بالموقع الأصلي في المشروع.
