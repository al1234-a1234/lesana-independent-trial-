# خريطة الأدلة والمنشأ

المصدر المحلي الوحيد للفحص السابق هو `lesana-security-audit.zip`. بصمته ومدخل الاختبارات المستعملان في `evidence/input-provenance.json`. قُرئت حزمتا محرك القصص وأدوات الصوت من الأرشيف مباشرة، وسُجلت بصمتاهما والعلامات الموجودة في `evidence/source-analysis.json`؛ يمكن إعادة ذلك بالسكربت المحلي `scripts/read-audit.py`. لم تُستورد حزم الإنتاج إلى التطبيق، ولم يُستخدم مفتاح Supabase المنشور أو أي صوت/نص مدفوع.

| المرجع السابق | السلوك المستفاد | الكود الجديد/الاختبار |
|---|---|---|
| J07–J08 والاختبارات المصطنعة | تطبيع ومقارنة حرفية ودقة تراكمية | `lib/engine.ts`، اختبارات core |
| J08–J09 | ألوان الأحرف وإكمال السطر رغم بعض الأخطاء | `typing-round.tsx`، اختبارات الخطأ والنهاية |
| J06 | تعامل لوحة المفاتيح وإعادة الصوت | حقل ظاهر متاح وصوليًا، واختصار backslash |
| J02–J03 | ملفات صوت ونطق بديل وسرعات | `audio-player.tsx`؛ MP3 أصلي لكل سطر |
| J05 | مؤثرات مولّدة محليًا | `lib/audio.ts`، نغمتان مستقلتان |
| J10–J12 | حفظ نتائج السطر وطابور وإكمال | `client-store.ts`، API، SQLite، journal/idempotency |
| J15 | واجهة مراجعة أقرب للأخطاء وأبعد للصحيح | تنفيذ مستقل في `scheduler.ts`؛ ليس نسخة من خوارزمية الخادم |
| J17–J18 | تفضيلات وترجمة عربية | إعدادات محلية وعرض/إخفاء الترجمة |

`evidence/audit-fixtures.json` يحتوي فقط بيانات مصطنعة مثل `cat` و`Hi, Sam!`. لم يُنقل كتالوج القصص أو بنك التحدي أو audio_path أو voice_id أو image_brief إلى المشروع.

## أدلة هذا المشروع

- `evidence/build.log`: بناء إنتاج فعلي.
- `evidence/unit-tests.tap`: تنفيذ الحالات المحلية.
- `evidence/playwright-results-initial.json` و`e2e-run-1.log`: التشغيل الأول بما فيه الإخفاقات.
- `evidence/playwright-results.json` و`e2e-run-final.log`: آخر تشغيل مع تفاصيل كل اختبار.
- `evidence/playwright-report/index.html`: التقرير التفاعلي.
- لقطات desktop/mobile والتصحيح والمراجعة داخل `evidence`.
- `public/audio/manifest.json`: النصوص الأصلية ومولدها وأحجام الصوت وبصماته.
- `evidence/release-smoke.json`: تشغيل نسخة ZIP مستخرجة وبقاء التقدم بعد إعادة تشغيل الخادم، دون متغيرات مطلوبة.
- `evidence/cost-model.json`: الحسابات وأسعار الوحدات والفرضيات.

اختبارات المتصفح تحجب أي hostname خارجي، وتفشل عند رصد أي طلب صفحة خارج localhost/127.0.0.1. هذا يثبت عدم اتصال تدفقات الاختبار بخدمات الإنتاج؛ بحث أسعار الموردين وتنزيل dependencies أثناء التطوير نشاطان منفصلان.
