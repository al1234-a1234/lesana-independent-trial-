# مخطط إعادة البناء وتسليم التنفيذ

هذا الملف يصف ما نُفّذ بالفعل. لا يفترض أن الخادم الأصلي أو جدول مراجعاته قد انكشف.

## المطالب ومكان تسليمها

| المطلوب | التنفيذ | دليل القبول |
|---|---|---|
| Next.js مستقل | مشروع App Router، dependencies مقيدة وlockfile | build.log وتشغيل إنتاج داخل Playwright |
| كتابة وتصحيح | محرك جديد وحالات صحيحة/خاطئة/مصححة وتطبيع | 7 حالات مصطنعة من الحزمة السابقة واختبارات UI |
| قصص أصلية | قطار السبت، حديقة فوق السطح، المعرض الصغير | JSON و18 سطرًا جديدًا |
| مشغل صوت | 18 ملف سطر + 18 كلمة، أربع سرعات | manifest، تشغيل وcurrentTime/readyState |
| حفظ تقدم | جلسة Cookie وSQLite، استئناف القصة | إكمال وتحديث وعزل جلستين |
| مراجعة | جدول مستقل واختيار حتى خمس جمل | اختبار وحدة للزمن واختبار جلسة مراجعة فعلي |
| تعطل الشبكة | حفظ journal محلي ثم مزامنة idempotent | اختبار قطع POST ثم استعادته |
| تقرير تكلفة | حاسبة قابلة للتشغيل وأسعار رسمية | cost-model.json ومصادر COST_ANALYSIS |
| ZIP قابل للتشغيل | المصدر وlockfile والصوت والأدلة | manifest وفحص الأرشيف |

## تسلسل البناء المنفذ

1. قراءة الاختبارات ومراجع J02–J18 من الأرشيف المتاح والتحقق من بصمته. لم تُعد زيارة الإنتاج.
2. كتابة محرك مستقل ومطابقته بالاختبارات المصطنعة المتاحة.
3. كتابة 3 قصص ورسوم SVG أصلية وإنشاء ملفات MP3 عبر Flite محليًا.
4. إنشاء تخزين جلسات منفصل وإعادة حساب نتيجة الكتابة على الخادم.
5. تطبيق جدول الفترات المعلن، وواجهة الاستئناف والقاموس والمراجعة.
6. تنفيذ build وtypecheck والوحدة وPlaywright على خادم الإنتاج المحلي.
7. إصلاح إعدادات الاختبار التي فشلت أولًا، ثم حفظ التشغيل النهائي والأدلة السابقة بشفافية.

## ما أُعيد وما استُبدل

أعيدت: المقارنة حرفيًا، الدقة التراكمية، أثر حذف الخطأ، تجاوز الترقيم اختياريًا، التحذير من العربية، حالات عرض المرجع، إكمال السطر دون اشتراط 100%، نطق ملف/جهاز، سرعات، طابور ومحاولات إعادة الحفظ.

استُبدلت باستقلال: قاعدة البيانات، جلسات الزوار، قواعد مراجعة 10 دقائق/أيام، بنك القصص، ملفات الصوت، تنظيم الواجهة، حفظ المحاولة idempotent وإعادة تحقق الخادم. لا تستعمل طبقة التخزين Supabase ولا استدعاء `record_line` الأصلي.

## مسار تطوير تالٍ، خارج النسخة الحالية

الحسابات ومزامنة الأجهزة، محرّر محتوى، قياس الاحتفاظ، وتقييم تعليمي للخوارزمية إضافات مستقلة. الدفع يحتاج نموذج صلاحيات ومسار وسائط خاص قبل إضافة أي مادة مدفوعة. يوضح `SECURITY_MODEL.md` حدود النسخة الحالية؛ لا يُعد غياب هذه الإضافات تنفيذًا مخفيًا لها.
